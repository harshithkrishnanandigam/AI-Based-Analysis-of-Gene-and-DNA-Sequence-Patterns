Molecular Biology Foundation

Pre-mRNA Splicing & The Problem Statement

Eukaryotic genes are "split genes" composed of coding Exons and non-coding Introns. The spliceosome must cut DNA with single-nucleotide precision.

Class 1: EI

Donor Splice Site (5')

Marks where an exon ends and an intron begins. Defined universally by the invariant canonical `GT` dinucleotide at the 5' boundary.

Class 2: IE

Acceptor Splice Site (3')

Marks where an intron ends and an exon begins. Characterized by a Polypyrimidine Tract (C & T) terminating in canonical `AG`.

Class 3: N

Neither / Non-Splice

Sequences located entirely inside an exon or intron that lack spliceosome cleavage activity.

⚠️ Clinical Significance

Over 15% to 50% of human disease-causing point mutations disrupt splicing, causing frameshifts that trigger cystic fibrosis, spinal muscular atrophy, and oncology.

System Engineering

End-to-End Pipeline & Feature Representation

How raw primate DNA sequences are transformed into an industrial machine learning pipeline:

1. Data Ingestion

3,178 Primates from GenBank 64.1 (UCI). 60-bp windows with splice site at center (pos 30/31).

2. Feature Space

91 Tabular Features: Mononucleotide counts/freqs, GC content %, 16 2-mers, and 64 3-mers (codons).

3. Zero-Leakage CV

5-Fold Stratified CV using sklearn.pipeline.Pipeline with StandardScaler fitted strictly on train folds.

4. Deployment

Streamlit Dashboard with real-time inference, color-coded sequence mapping, and batch FASTA processing.

Explainable AI (XAI)

Autonomous Biological Motif Discovery

The model was given zero hardcoded biological rules—only raw nucleotide strings. Yet tree feature importances rediscovered textbook biology:

1. 5' Donor Consensus 'GT'

Top Ranked: `3mer_GGT` & `3mer_GTA`
Matches the universally conserved invariant GT dinucleotide bound by U1 snRNA.

2. 3' Acceptor Consensus 'AG'

Top Ranked: `3mer_AGG` & `3mer_CAG`
Matches the canonical terminal AG intron consensus recognized by U2 snRNA.

3. Polypyrimidine Tract

Top Ranked: `2mer_TC`, `3mer_CTC`, `3mer_TCT`
Dense runs of C and T recognized by the U2AF65 splicing factor.

🌟 Key Takeaway for Panel: This proves mathematically that the AI is not hallucinating or memorizing noise; it is capturing genuine biochemical signals.
